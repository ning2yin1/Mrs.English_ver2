# Mrs. English

iPhone横画面向け、日本語中心の英語学習PWAです。ルートの制作キットは入力資料としてそのまま保持し、この `app/` にアプリを実装しています。React / TypeScript / Vite、端末内IndexedDB、外部アプリAPI・サーバー・課金なし、プレイ回数無制限です。

## 開発・検証

Node.js 24、Python 3.12を使用します。アプリ依存は `package-lock.json` に固定しています。

```sh
cd app
npm ci
npm run dev
```

`predev` / `prebuild` が原本を変更せず `public/` に配信用の写真・枠・SVG・WAV・フォント・アイコンを生成します。写真は比率を保持して縮小し、背景最大1920px、カード最大900pxで出力します。

```sh
npm test
npm run build
npm run test:e2e
npm run verify:data
```

教材QAには `jsonschema==4.26.0` と `referencing==0.37.0` が必要です。E2EはPlaywrightのChromiumを使用し、Linuxで `/usr/bin/chromium` があればそれを使用します。ない場合は `npx playwright install --with-deps chromium` を実行してください。ブラウザー試験は844×390と667/812/844/852pxの横画面を含みます。

`npm run preview` は完成ビルドのローカル確認用です。開発サーバーはオフラインキャッシュを登録しません。既存の分離されたチェックアウトを使用し、明示的に依頼されない限りGit worktreeは作成しません。

## 機能

- 固定TOPタイトル、名前・推し・22背景の設定、3メンバー保証の初回無料10枚パック、途中からの開封再開。
- 60文法、600例文、1,800問、EASY / NORMAL / HARD。句ブロックのタップ移動、時間切れ後も回答継続、回転・背面化で停止。
- 仕様のスコア・星・カード倍率・星差分RP、難易度別ベスト、結果と解説・語彙・端末TTS、苦手問題の復習。
- 元写真の79カード、3人編成、おすすめ編成、Lv強化、図鑑、1枚/10枚RPショップ、重複還元。
- 日本時間のログイン・日/週ミッション・連続学習・記録、設定、JSONバックアップと検証後の全置換。
- 特典・購入・強化・完了・ミッションの台帳イベントと、関連データを同一IndexedDBトランザクションで保存。複数タブは旧タブを停止。
- 復元前のバックアップはダウンロードと別の端末内DBにも保管。設定のバックアップ画面から再保存可能。
- ハッシュ確認付きService Workerキャッシュ。全ファイル確認後に版を切替え、ユーザーセーブは削除しません。

バックアップは破損検出用SHA-256付きです。署名・不正対策ではなく、端末だけで使う個人セーブです。古いバックアップの復元は、その時点への巻戻しになります。

## 個人用の公開

**公開ホストへ送るのは `app/sealed/` だけです。`app/dist/`、リポジトリ全体、元写真ディレクトリを公開しないでください。**

`scripts/seal.mjs` はアプリ本体と全写真・教材をファイルごとにgzip圧縮し、PBKDF2-SHA256（600,000回）とAES-256-GCMで暗号化します。合言葉はブラウザーから送信せず、端末内のService Workerで復号します。配信ホストに置くのは解除画面と暗号文だけです。Cloudflare Pagesの1ファイル上限に余裕を持たせるため、暗号文は8MiB以下に分割します。端末では最大4ファイルずつ検証・保存し、全素材を巨大なJSON文字列に展開しません。初回解除後、検証済みのファイルを端末内にキャッシュします。

これは合言葉を知る人向けの配信です。サーバー側の本人認証・個別の失効管理ではありません。URLだけでは写真を取り出せませんが、暗号文は取得できるため、パスワードマネージャーで生成した**32文字以上の推測困難な合言葉**を推奨します。合言葉・解除済み端末・バックアップは他人と共有しないでください。設定で「この端末の配信をロック」すると復号キャッシュだけを削除し、セーブは保持します。既に解除した端末から素材を回収する仕組みではありません。

GitHubリポジトリ自体がPublicであれば、そこにある元キットは別途閲覧可能です。この作業ではリポジトリの公開範囲を変更していません。GitHub APIへ接続できなかったため、公開範囲の確認は未完了です。

### Cloudflare Pages無料枠と自動公開

Cloudflareのアカウント・プロジェクト・APIトークンがまだこの環境には提供されていないため、公開URLはまだ発行していません。次の設定後、main更新 → テスト → 暗号化 → 公開が自動で行われます。

1. Cloudflare Dashboard → Workers & Pages → Pages → **Direct Upload** のプロジェクトを作成。任意のプロジェクト名、production branchは `main`。平文のファイルをアップロードする必要はありません。Git連携方式ではなくDirect Upload方式を選びます。
2. CloudflareのAPI tokenを、対象アカウントの **Account / Cloudflare Pages / Edit** のみに制限して発行し、Account IDを確認。
3. GitHubのこのリポジトリ → Settings → Secrets and variables → Actions に、次を設定。

| 種類 | 名前 | 内容 |
|---|---|---|
| Secret | `CLOUDFLARE_API_TOKEN` | 上記APIトークン |
| Secret | `CLOUDFLARE_ACCOUNT_ID` | 対象Account ID |
| Secret | `SITE_PASSPHRASE` | 自分だけの合言葉。16文字未満・空白だけはビルド拒否 |
| Variable | `CLOUDFLARE_PROJECT` | 作成したPagesプロジェクト名 |

4. Actions → **Test and privately publish Mrs. English** → **Run workflow** → `main`。成功するとCloudflare Pagesの画面にHTTPSのproduction URLが表示されます。以後はmainへのpushで自動公開されます。

`.github/workflows/app.yml` はPRとmainの教材QA・単体・ビルド・E2Eを実行します。公開用変数が未設定の間はデプロイだけをスキップします。PRからは公開せず、合言葉が未設定なら平文公開に切り替えず失敗します。写真入りスクリーンショットや平文ビルドをActions artifactとして公開する処理もありません。サービスのプラン・利用条件は設定時に確認してください。有料契約やリポジトリ公開範囲の変更は不要な構成ですが、それらを求められた場合は操作を進めないでください。

公開後は、未解除ブラウザーから元写真パスが404であること、合言葉解除、タイトル画像、初回10枚、10問プレイ、オフライン再起動をproduction URLで再確認してください。ローカルの同じ配信方式では検証済みですが、実際の公開サービス上の確認は未実施です。

### iPhoneの使い方

1. HTTPSのproduction URLを**Safari**で開き、合言葉を入力。初回は約25MBの配信を受信し、素材の検証・端末への保存が終わるまで待ちます。
2. iPhoneの回転ロックを解除して横向きにします。縦向き時は案内を表示し学習を停止します。OSの横向き固定成功には依存しません。
3. ニックネーム → 推し → 背景 → 無料10枚を開封 → ホーム。
4. START → 文法01 / EASY → 開始 → 10問。結果のRP・星、レビューと音声を確認してください。
5. Safariの共有ボタン → **ホーム画面に追加** → 追加。以後はそのアイコンから起動できます。Safariタブとは保存領域の扱いが異なることがあるため、追加後も確認してください。
6. 設定で「オフライン準備完了」を確認後、通信を切って再起動。音声がない場合も文字による学習と保存は継続できます。

最新のSafari（暗号化配信はDecompressionStreamをサポートするiOS 16.4以降）を前提としています。英語読み上げは端末TTSで、録音音声600本ではありません。ローカル英語voiceの導入・機内モードでの再生、Safari/ホーム画面追加での音声開始、切欠きとホームバー、文字拡大、容量不足時の挙動はiPhone実機での確認が必要です。端末のデータ消去でセーブが失われるため、定期的にバックアップしてください。
