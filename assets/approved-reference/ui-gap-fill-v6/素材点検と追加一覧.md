## 素材の状態

- 6枚とも複数の部品をまとめたPNGシートです。個別ファイルへの切り出しは未実施です。
- 文法表紙、空・システム状態、ガチャ、星・所持状態の4シートは、比較しやすい青背景付きです。
- 共通バーと正誤・中断表示の2シートは透過指定で生成しています。半透明の縁や光彩を含みます。
- 生成画像の配置・文字・線の太さは、実装前に元素材と照合して調整する前提です。
- 開封や読み込みの表示は静止画案です。動くアニメーションや動作するUIは含みません。
- 表紙の単元名や時間切れなどは候補で、機能や学習ルールを確定するものではありません。

## 既存素材で対応できるもの

- 背景・集合写真・メンバー写真・ランク枠・カード裏面: asset-reviewの元素材。
- 空の結果／解説パネル・解答選択肢: ui-materials-proposal-v2。
- ミッション・通知・設定・基本アイコン・演出: ui-materials-expansion-v3。
- CLEARED・PERFECT・NEW RECORD・TRY AGAIN: ui-wordmarks-v4。
- 完成画面の参照: screen-mockups-v5。

## 画像生成とは別に必要な作業

採用した素材の切り出し・余白整理・縮小表示の調整、既存アイコンのPWA用サイズ書き出し、フォント選定、問題・解説・音声、音響効果、採点ルール、アニメーション制御は別途必要です。
今回、アプリ実装や既存ファイルの置き換えは行っていません。
生成指示と参照画像はgeneration-manifest.jsonに記録しています。
