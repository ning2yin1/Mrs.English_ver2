- 01-reference-cleared/cleared.png: スクリーンショットのCLEAREDを参照したロゴ。
- 02-study-candidates/perfect.png: 全問正解などに使える候補。
- 02-study-candidates/new-record.png: 自己ベスト更新に使える候補。
- 02-study-candidates/try-again.png: 再挑戦や復習に使える候補。

追加3語は学習アプリ向けの提案です。元ゲームにこの表記が存在することを確認したものではありません。

生成に使用した指示と参照ファイルはgeneration-manifest.jsonに記録しています。
