# 文法60項目

学年は学習順の目安であり、特定の教科書の配当を示しません。

|ID|文法|目安学年|学習目標|
|---|---|---|---|
|G01|be動詞の肯定文|中1|人や物の状態をam・is・areで表す。主語Iはam、単数はis、複数とyouはare。|
|G02|be動詞の否定文|中1|be動詞の後ろにnotを置く。主語とbe動詞の一致にも注意する。|
|G03|be動詞の疑問文|中1|be動詞を主語の前に置いて質問する。疑問符まで含めて確認する。|
|G04|冠詞と名詞の複数形|中1|aは子音で始まる音、anは母音で始まる音の前で使う。複数形の名詞にはa・anを付けない。|
|G05|所有格と所有代名詞|中1|名詞の前にはmy・yourなどの所有格、単独ではmine・yoursなどの所有代名詞を使う。|
|G06|代名詞の目的格|中1|動詞や前置詞の後ろではme・him・her・us・themなどの目的格を使う。|
|G07|一般動詞の現在形|中1|I・you・we・theyなどを主語にして、習慣や普段の行動を動詞の原形で表す。|
|G08|三人称単数現在|中1|主語がhe・she・単数の人や物なら、現在の一般動詞にs・esなどを付ける。|
|G09|一般動詞の否定文|中1|I・you・we・theyにはdo not、三人称単数にはdoes notを使い、その後を原形にする。|
|G10|一般動詞の疑問文|中1|Do・Doesを主語の前に置く。Doesの後ろの動詞も原形にする。|
|G11|what・whoの疑問文|中1|whatは物事、whoは人を尋ねる。疑問詞を文の先頭に置く。|
|G12|where・whenの疑問文|中1|whereで場所、whenで時を尋ねる。一般動詞の疑問文は疑問詞＋do・didなどで作る。|
|G13|why・howと程度の疑問文|中1|whyは理由、howは方法や状態を尋ねる。How old・How manyなどのまとまりも使う。|
|G14|which・whoseと選択疑問文|中1|whichは選択、whoseは持ち主を尋ねる。A or Bで選択肢を示せる。|
|G15|There is・There are|中1|There is＋単数、There are＋複数で存在を伝える。there自体は物や人の主語ではない。|
|G16|場所・方向の前置詞|中1|in・on・under・toなどで位置や方向を示す。日本語の位置関係を手掛かりに選ぶ。|
|G17|時を表す前置詞|中1|時刻にはat、曜日や日付にはon、月や年・朝などにはinを使う。|
|G18|命令文・勧誘|中1|動詞の原形で指示し、Do notで禁止する。Let usで一緒に行動する提案をする。|
|G19|canの能力・可能|中1|canの後ろは動詞の原形。cannotでできないこと、Can＋主語で質問を表す。|
|G20|数量表現・可算と不可算|中1|manyは数えられる複数名詞、muchは不可算名詞に使う。someは肯定文、anyは否定・疑問でよく使う。|
|G21|現在進行形|中1|be動詞＋動詞のing形で今進行中の動作を表す。主語とbe動詞を一致させる。|
|G22|be動詞の過去形|中1|過去の状態をwas・wereで表す。Iと単数はwas、youと複数はwere。|
|G23|一般動詞の過去形・規則動詞|中1|規則動詞にed・dを付けて過去の動作を表す。子音字＋yはiedにする。|
|G24|一般動詞の過去形・不規則動詞|中1|go→went、buy→boughtなど、edを使わない過去形を確認する。|
|G25|一般動詞の過去の否定・疑問文|中1|did notの後ろは原形。疑問文はDid＋主語＋原形の順にする。|
|G26|過去進行形|中2|was・were＋ing形で過去のある時点で進行していた動作を表す。|
|G27|be going toによる未来|中2|be going to＋原形で予定や見込みを表す。be動詞を主語に合わせる。|
|G28|willによる未来・意志|中2|will＋動詞の原形で予測や意志を表す。willの形は主語で変わらない。|
|G29|must・have to・禁止と不要|中2|must・have toは義務。must notは禁止、do not have toは必要がないことを表す。|
|G30|should・mayと丁寧な依頼|中2|shouldは助言、mayは許可や可能性。Could you・Would youは丁寧な依頼の形。|
|G31|比較級|中2|二つを比べるときに比較級＋thanを使う。長い形容詞はmore、不規則形はbetterなど。|
|G32|最上級|中2|三つ以上の中で一番をthe＋最上級で表す。範囲にはin・ofなどを使う。|
|G33|as ... asの原級比較|中2|as＋形容詞や副詞の原級＋asで同じ程度を表す。not as ... asでそれほどではないことを示す。|
|G34|不定詞・名詞的用法|中2|to＋動詞の原形を「～すること」としてwant・hopeなどの目的語にする。|
|G35|不定詞・目的を表す副詞的用法|中2|to＋原形を「～するために」として動作の目的を付け加える。|
|G36|不定詞・形容詞的用法|中2|名詞の後ろにto＋原形を置いて「～するための・～すべき」と説明する。必要な前置詞も残す。|
|G37|動名詞|中2|動詞のing形を「～すること」として使う。enjoy・finishや前置詞の後ろで使える。|
|G38|授与動詞・SVOO|中2|give・showなどの後ろに「人＋物」の順で目的語を二つ置く。to・forを使う型とは区別する。|
|G39|SVC・感覚動詞|中2|look・sound・feel・becomeなどの後ろに形容詞や名詞を置き、主語の状態を説明する。|
|G40|SVOC・make・call・keep・let・help|中2|目的語を補語で説明する型と、let・help＋人＋動詞の原形を学ぶ。make＋人＋原形も基本の形。|
|G41|and・but・or・so|中2|andは追加、butは対比、orは選択、soは結果を結ぶ。日本語のつながりを確認する。|
|G42|because・when・before・after|中2|becauseは理由、whenは時、beforeは前、afterは後を示す。従属節も主語＋動詞にする。|
|G43|ifの条件文|中2|if節で条件を表す。未来のことでもif節では現在形を使い、主節にwillなどを使う。|
|G44|that節・感情の理由|中2|think・knowなどの目的語にthat＋主語＋動詞を使う。be glad thatでも気持ちの理由を示せる。|
|G45|間接疑問文|中3|疑問詞の後ろを主語＋動詞の語順にする。do・does・didを疑問文の形で残さない。|
|G46|疑問詞＋to不定詞|中3|how toは方法、what toは何をするか、where toはどこで行うかを簡潔に表す。|
|G47|want・ask・tell＋人＋to|中3|want・ask・tellの後ろに人＋to不定詞を置き、人にしてほしいことや頼む内容を示す。|
|G48|It is ... for ... to|中3|長い主語の代わりにitを置き、for＋人で動作をする人、to不定詞で内容を示す。|
|G49|too ... to・enough to|中3|too＋形容詞＋toは程度が強くてできないこと、形容詞＋enough＋toはできる程度を表す。|
|G50|受け身の現在形|中3|am・is・are＋過去分詞で「～される」を表す。動作を受ける人や物を主語にする。|
|G51|受け身の過去形|中3|was・were＋過去分詞で過去にされたことを表す。主語の単複に合わせる。|
|G52|現在完了・経験|中3|have・has＋過去分詞にever・never・回数表現を添え、今までの経験を表す。過去の日時と併用しない。|
|G53|現在完了・完了と結果|中3|have・has＋過去分詞で現在につながる完了・結果を表す。just・already・yetも確認する。|
|G54|現在完了・継続とfor・since|中3|状態が過去から今まで続くことを現在完了で表す。forは期間、sinceは開始時点。|
|G55|現在完了進行形|中3|have・has been＋ing形で過去から今まで続いている動作を表す。|
|G56|関係代名詞・主格|中3|人にはwho・that、物にはwhich・thatを使い、名詞を後ろから説明する。ここでは指定された関係詞の型を使う。|
|G57|関係代名詞・目的格と省略|中3|名詞の後ろに主語＋動詞を置いて目的語の役割を説明する。目的格のthat・whichは省略できる。|
|G58|分詞の後置修飾|中3|名詞の後ろでing形は「～している」、過去分詞は「～された」という説明を加える。|
|G59|基本的な仮定法・I wish|中3|現実と異なる願いをI wish＋過去形、仮の条件をIf＋過去形とwould・couldで表す。|
|G60|感嘆文|中3|How＋形容詞・副詞＋主語＋動詞、What＋a・an＋形容詞＋名詞＋主語＋動詞で感動を表す。|
