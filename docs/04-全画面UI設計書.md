# 横画面・全画面UI設計

## 共通座標とルール

画面は安全領域を除いた横844×390 CSS pxを基準とする。実機の幅・高さに合わせて余白を伸縮し、ラベル・タップ領域を単純に縮小しない。最低ターゲット44×44px、間隔8px、基本本文16px、問題英文24〜30px、補助13px。日本語は端末標準Hiragino Sans/sans-serif、数字・判定は同梱の候補フォントまたはcondensed sans。最小対応横領域は667×320。横長画像を縦に引き伸ばさない。16:9では内容領域を中央、広い画面は背景だけ広げる。

安全領域safe-area-inset-*を必ず上下左右に適用。高さ390基準で上部バーy0〜42、主領域y50〜328、下部メニューy336〜390。主領域の左端x12、右端x832。タイトル等フルスクリーンとプレイは上部を専用HUDへ置換。モーダルはx110,y56,w624,h278、長文レビューはx36,y48,w772,h300で内部スクロール。ダイアログの確定・キャンセルはスクロールと独立して固定。

縦持ちではアプリを90度CSS回転させず「端末を横向きにしてください」の回転案内を全面表示。プレイ時間を停止し、未入力内容を保持。戻すと再開ボタン。OS回転ロック自体の解除はアプリからできる前提にしない。

色:背景#08162C、面#194D84、濃面#102E52、線#B5FAF7、シアン#2BB9E8、マゼンタ#FF009E、紫#4B2CA0、本文#FFFFFF、補助#B7CFDF、警告#FFCD42。左上・右下を8〜12pxで斜めカット。外枠2px、pinkオフセット2px。背景黒55%、文章面92%。押下90msでbrightness .85、選択シアン線、無効opacity .45。色以外にチェック・文字・枠で状態を示す。

上部バー:プロフィール領域x8〜310、学習Lv310〜400、連続400〜510、RP510〜720、メニューx784〜836。フォント幅で衝突する場合は推し名を2行表示しRPは省略せず残す。下部5メニューは等分幅、STARTのみ白＋pink。図鑑とカードを区別する。ホーム中央は写真の顔周辺x270〜610を空け、入口は左x12〜236、右x640〜832。

## UI文言の固定

カード／図鑑／ミッション／ショップ／学習記録／苦手問題の復習／編成する／おすすめ編成／強化／所持済み／未取得／入手日／戻る／決定／再開／前の問題／次の問題／音声を再生／受取済み／RPが足りません／保存しています／端末を横向きにしてください。
OBTAINED→入手、INVENTORY→所持カード、EQUIP→編成する。下部の旧CARDS・GACHA・GRAMMAR・RECORDSは今回の本番ラベルではない。直感的なREADY、START、判定語、TOTAL SCORE、LEVEL UP、NEW RECORDは許可。ゲーム上の問題文字・数値は画像に焼き込まない。

## 画像の適用順位

TOP、写真22枚、カード79枚、ランク5枠、裏面は元ZIPを本番に使う。新規の横画面9枚は雰囲気・配置の参考であり、生成画像から顔や文字を切り抜かない。新規モックで残った装飾・架空レベル・誤字・サンプル数値より、本設計書・規則JSONの内容を正とする。縦画面で生成しかけた画像は最終キットに含めない。

## 全画面の確認条件

長いニックネーム、RP最大表示、カード名折返し、HARDの長文と余剰語、システム文字拡大、端末のホームインジケータを確認。音声・色・ドラッグだけに依存した操作を作らない。右端の操作をiPhoneの切欠き下へ置かない。入力中の仮想キーボードはフォーカス欄と決定を見える位置にスクロールする。
