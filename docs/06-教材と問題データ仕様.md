# 教材・問題・音声データ仕様

## ファイルの役割

- curriculum.json:60項目のID、名称、学年目安、学習目標、順序、10例文ID。
- examples.json:600例文の正本。英文と和訳、対象文法、穴埋め座標、各難易度データ、解説、語彙、音声本文。
- questions.json:1,800問の平坦な配布データ。EASY/NORMAL/HARDが同じexampleIdを参照し、canonicalEnglishは完全一致。
- by-grammar/G01.json〜G60.json:10例文ずつの分割。低メモリー端末用。examples.jsonと二重編集しない。
- tts-manifest.json:600件の読上げデータ。1例文1音声IDを3難易度で共有。
- 教材全600例文.md:人が確認できる和訳・解説・選択肢・答えの一覧。
- schemas/:標準JSON Schema。Codexは読込時とビルド時に検証。

全例文はオリジナルの創作シーン。バンドの実際の私生活、ライブ開催、発言や習慣を記録したものではない。初回チュートリアルとレビューの上部に「例文は学習用の創作です」を表示する。歌詞を転載しない。固有名詞はMrs. GREEN APPLEの名称のみ使用し、日付付きの実際の活動を断定しない。中1〜中3は配列設計の目安で、教科書ごとの学年配当と一致する保証ではない。

## 学習範囲

be・一般動詞・代名詞・冠詞数量・疑問詞・前置詞・命令・助動詞・進行・過去・未来・比較・不定詞・動名詞・文型・接続詞・間接疑問・不定詞構文・受け身・現在完了3用法・現在完了進行・関係代名詞・分詞・仮定法・感嘆文を60項目に整理した。現行中学範囲の確認には文部科学省資料を参照した。高校の複雑な仮定法過去完了・非制限関係節・分詞構文・倒置等を独立単元にしない。

## 座標と選択肢

grammarFocus.start/endExclusiveはcanonicalEnglishの0始まり文字位置（英文はASCIIなのでUTF-16の添字と一致）。[]は原稿の注記で、配布英文には含まれない。easy.promptは対象部分を___へ置換。optionsは安定ID付き4つ、correctOptionIdで正解。配布時の順は固定seedで分散しており、実プレイではさらにシャッフルする。正解の位置に偏りを作る規則を実装しない。

EASYは和訳・文法名を必ず併記。人称・時制・数量・意味のどれを満たすかが問題の条件。英語として別の場面では成立する選択肢も、指定和訳と文法に合わなければこの問題の答えではない。「その選択肢は英語として常に誤り」と説明しない。形容詞と副詞、主語と動詞、助動詞の後ろの原形などを学べる選択肢を用意している。

## 並び替えの正解判定

blocksは句ブロックであり、textに含む空白を分解しない。日本語訳はNORMAL/HARDで同一。correctOrderは必要IDの順序。HARDのdistractorBlocksにはrole=distractorを明示するが、プレイヤーにはその属性を見せない。不要語は5個以上、時間基準には数えない。

判定は選択したID列を文字列に変換し、正解順のブロックtext列と比較する。重複textのブロックIDを入れ替えただけなら正解。例:「I / ... / I / ...」の同じIに別IDがあってもよい。バンク中の不要語と必須語はtextが同一にならないよう検査済み。

基本の制約は主語先行、付加語句は文末、主節先行。疑問・命令・感嘆は学習した型を優先。自由英作文の全自然語順を自動採点する機能ではない。「基本語順で並べる」という条件をお題の補助に示す。文法的な別表現を無条件にMISSと言い切る説明はしない。関係代名詞who/that、目的格の省略など同義の代替は解説で紹介するが、提示されていない語に入れ替えることはできない。この句ブロック設計で、必要語すべてを使う基本語順の答えを一つに絞る。

correctOrderにない自然語順を今後追加する場合は、acceptedOrdersへ編集者が明示登録し、同じ和訳・指定文型と一致することを確認する。英語の意味の同一性はID並べ替えの機械検査では証明できないため、未登録を「英文として絶対に誤り」と表示しない。

## 解説・語彙

grammarFocus.explanationJaは項目の規則。sentenceExplanationJaは当該英文・和訳・対象部分と句の並びを含む。glossaryは単語の文脈に使える語義、活用の見出し語、熟語を記録。音楽・musicは文脈で音楽/楽譜、takeは取る/乗るなど多義語をまとめ、必要な熟語には独立語義を付けた。正誤レビューでは正解部分を色だけでなく下線でも示す。

音声はaudio.textに正しい英文全体、lang=en-US、rate=.9、pitch=1を指定。preRecordedPath=nullは録音音源が存在しないという意味。mp3を同梱したという誤表示をしない。端末内英語voiceを優先し、voiceschangedとgetVoicesを両方扱う。ユーザーの音声ボタンタップから再生し、別の問題へ移動するとcancel。音声再生時間はプレイ計時に影響させない（レビュー時のみ再生）。

ネット不要の音声を必須とする配布環境では、Codexが端末のローカルvoice再生を機内モードで実機確認する。使えない場合は「端末の英語音声が利用できません」と表示して学習続行。確実な全端末オフライン音声保証が必要になった場合の差替え先として各IDのpreRecordedPathを用意している。

## 検証と編集

600件の英文・和訳・学習対象・選択肢を執筆時に見直し、同義の関係代名詞を誤答候補から外した。動名詞の名詞補語に同義のto不定詞を混ぜない修正、miss a concertの和訳修正、3組の重複文の差替えを実施。構造と意味の検査を混同しない。qa/validation-report.jsonの全件検査は件数・ID・選択肢・答え復元・タイマー・参照の整合性を検証し、自然言語の完全性を証明するテストではない。出題前に教材全600例文.mdを編集画面から参照できるようにする。

原稿と変換用ツールはauthoringに同梱。変更は原稿→生成→QAの順で行い、questions.jsonだけを手で変更してexamples.jsonと食い違わせない。
